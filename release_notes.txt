## What's New in v1.1.0

- **Run on Startup Installer Option:** Added a new custom checkbox for "Run on Windows startup" directly on the NSIS setup finish page.
- **Independent Shortcut Customization:** Restored the standard "Create Desktop Shortcut" checkbox so users have full freedom to toggle both settings independently.
- **Silent Boot (System Tray):** The application now properly detects the --autostart flag from the registry to launch silently into the system tray on boot without flashing the GUI.
- **Registry Sync:** The app's settings automatically sync with the registry to correctly reflect the installer's startup choice.
- **No More Command Prompts:** Fixed an issue where triggering a recording via hotkey would briefly flash a command prompt window by explicitly silencing the internal fmpeg process.
- **Robust Output Directories:** The app now automatically handles missing recording directories by creating them automatically on the fly.
- **UI & Dual Monitor Tweaks:** Expanded the Settings window size and improved fallback handling for multi-monitor displays when determining the overlay's home monitor.

## What's New in v1.1.3

- **Common-clock AV sync:** one shared recording start for video and every audio track; per-track offsets logged in ms (positive = audio late) and included in the stop result; drift correction keeps sync over short and 10+ minute recordings.
- **Validation + retry:** final files validated (missing, 0-byte, `moov` check) before success is reported; failures show a non-technical error and keep temp artifacts for retry without re-recording; enabled-but-empty audio tracks warn naming system vs mic.
- **Annotation overlay:** pen, marker, arrow, text, eraser, and clear-all with color and thickness controls; overlay Draw button plus `Ctrl+Shift+Alt+A` hotkey toggle with armed/disarmed state; `Esc` exits draw mode only; marks burn into the video pixels.
- **Post-stop save dialog:** modal with editable timestamp-prefilled name, Save / Delete Locally, inline validation (empty, illegal characters, reserved names, overlong), explicit overwrite confirm, double-click safe, `Enter` saves and `Esc` keeps the default name.
